# DOCUMENTAÇÃO DO PROJETO TITRATION CALCULATOR
Data: 13/04/2025

## VISÃO GERAL DO PROJETO
O Titration Calculator é uma aplicação web/mobile que permite aos usuários visualizar e entender curvas de titulação ácido-base. A aplicação foi desenvolvida usando Next.js e convertida para aplicativo móvel usando Capacitor.

## FUNCIONALIDADES PRINCIPAIS
- Visualização de curvas de titulação para diferentes cenários
- Cálculos de neutralização para titulações de base forte com ácido forte
- Interface responsiva para web e dispositivos móveis
- Explicações detalhadas sobre o processo de titulação

## COMANDOS IMPORTANTES UTILIZADOS

### Comandos Next.js
```bash
npm run build       # Gerar build de produção
```

### Comandos Capacitor
```bash
npx cap init "Titration Calculator" com.titrationcalc.app  # Inicializar Capacitor
npx cap add android  # Adicionar plataforma Android
npx cap copy android  # Copiar arquivos web para Android
npx cap open android  # Abrir projeto no Android Studio
```

### Comandos Android
```bash
# Limpar pasta public antes de copiar arquivos
rm -r -force public
mkdir public

# Copiar arquivos de build para pasta public
xcopy /E /I out public
```

## ESTRUTURA DE ARQUIVOS PRINCIPAIS
- **next.config.js**: Configuração do Next.js com opções para build estático
- **capacitor.config.json**: Configuração do Capacitor para build mobile
- **src/components/ScenarioSelector.jsx**: Componente para seleção de cenários de titulação
- **src/lib/titrationCalculations.js**: Cálculos para diferentes cenários de titulação
- **src/app/layout.jsx**: Layout principal da aplicação
- **src/app/page.jsx**: Página principal da aplicação
- **android/**: Projeto Android gerado pelo Capacitor

## CONFIGURAÇÕES IMPORTANTES

### next.config.js
```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  // Enable React strict mode for better development experience
  reactStrictMode: true,
  
  // Output as a static website for better compatibility with Capacitor
  output: 'export',
  
  // Configure asset prefix for mobile app
  assetPrefix: '.',
  
  // Disable image optimization since we're building for mobile
  images: {
    unoptimized: true
  }
};

module.exports = nextConfig;
```

### capacitor.config.json
```json
{
  "appId": "com.titrationcalc.app",
  "appName": "Titration Calculator",
  "webDir": "public",
  "server": {
    "androidScheme": "https"
  }
}
```
